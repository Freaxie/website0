# Puer Aeternus

An interactive exhibition in seven rooms on the puer aeternus, the eternal youth, and his counterpart the
senex, the old man: flight and weight, beginning and duration, "not yet" and "already". After Ovid, Jung,
Marie-Louise von Franz and James Hillman. React + Vite + Framer Motion, SVG, canvas and CSS.

```
npm install
npm run dev              # local development
npm run build            # static site in dist/
npm run build:artifact   # single-file page in artifact/index.html
```

## Rooms

1. **Entrance.** PUER floats in a pale sky among rising feathers; the pointer lifts its letters. SENEX sits
   half sunk in a lead ground; pressed, its letters sink and take a long time to rise.
2. **Two Figures.** Not yet / Already, Possibility / Limit, Flight / Ground, Inspiration / Discipline,
   Beginning / Duration. The youth's words float; the old man's land.
3. **The Provisional Life.** Time runs while you look. Possible lives float in the sky, each with a
   window that closes; commit to one and it lands and grows. Von Franz's "provisional life".
4. **The Middle Course.** Fly Icarus between the sun, which softens the wax, and the sea, which soaks the
   feathers, as Daedalus told him to in Ovid's Metamorphoses VIII.
5. **One Archetype.** A slider from puer to senex grows a tree: all loose shoots at one end, all trunk and
   roots at the other, a tree in between. After Hillman's "Senex and Puer" (1967).
6. **Lineage.** Kronos, Ovid's "tu puer aeternus", Dürer's Melencolia I, Peter Pan, Jung, The Little
   Prince, von Franz and Hillman.
7. **Coda.** The puer begins. The senex keeps.
