# Generalist & Specialist

An interactive exhibition in eight rooms on two ways of spending a lifetime of attention: across many
fields, or down into one. React + Vite + Framer Motion, SVG and CSS.

```
npm install
npm run dev              # local development
npm run build            # static site in dist/
npm run build:artifact   # single-file page in artifact/index.html
```

## Rooms

1. **Entrance.** A band of twenty fields in eight colours, and one blue shaft dropping from it: the T.
   The letters of GENERALIST keep changing typeface; SPECIALIST never does. Sound the shaft for hours of depth.
2. **Two Kinds of Knowing.** Range and Focus, Connection and Precision, Analogy and Method,
   Adaptability and Authority. Hover a row to see its counterpart.
3. **The Fox & the Hedgehog.** Sort thirteen writers the way Isaiah Berlin did in 1953, then compare.
   With Philip Tetlock's forecasting study (2005).
4. **The Pin Factory.** Adam Smith's ten workers, making whole pins or dividing the labour, with his
   own warning from Book V.
5. **Kind & Wicked.** A toy model with invented numbers: slide from a stable world to a shifting one and
   watch a specialist and a generalist solve problems. After Robin Hogarth and David Epstein.
6. **Shapes of a Life.** Ten people drawn as the shape of their knowledge, from Leonardo to Andrew Wiles.
7. **Your Shape.** Draw your own: I, T, comb or dash.
8. **Coda.** The generalist sees how things connect. The specialist sees how one thing works.

The generalist is set in eight colours and five typefaces. The specialist uses one blue, close to
International Klein Blue, and one narrow face.
